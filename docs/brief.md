# ORQENSA working brief

An original architecture/interiors React portfolio concept by Rafayel Karamyan.
Raf deferred the personal portfolio and asked for one more project with a stronger
visual and interaction standard. Existing releases stay intact.

## Experience

A typographic split hero, asymmetric project index, four fictional spatial studies,
material library, an interactive 6 × 4.5 m room, saved layouts and a local brief
builder. Licensed reference photographs are credited; photographs and concept
studies are not represented as client commissions or Raf's architectural work.

The room supports adding, moving, rotating and removing furniture, keyboard
controls, collision/bounds checks, undo/redo, material/light choices, a lazy 3D
view with an SVG plan alternative, local persistence, portable snapshots and SVG
exports. A project brief is reviewed and downloaded, never falsely sent.

## Direction

Bone paper, charcoal typography and cobalt blue; Manrope and IBM Plex Mono.
Oversized typographic forms, architectural rules, asymmetric photography,
image-mask transitions and scroll-driven framing. Responsive layouts, readable
text during animation, reduced motion and an explicit motion pause.

## Delivery

React/strict TypeScript, GSAP and optional R3F/Three.js; GitHub Pages, no paid
service, extra hosting account or Render. Public author: Rafayel Karamyan.

Browser tests run on GitHub Actions before Pages deployment. Verification notes
distinguish executed checks from prepared checks and manual inspection.
